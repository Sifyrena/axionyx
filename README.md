# AxioNyx 1.1

This is the public release of the Axionyx Branch that Frank Wang modified as part.
It is used to produce the results described in the Mixed DM LyA paper https://arxiv.org/abs/2604.06038

# AxioNyx 1.0
axionyx is a modification of the the [Nyx code](https://github.com/AMReX-Astro/Nyx.git) for dealing with Fuzzy Dark Matter. The AxioNyx paper https://arxiv.org/abs/2007.08256 was produced using the mixed_dm branch.

# Getting Started

clone both the axionyx and the amrex4axionyx repo. axionyx expects amrex to live in ../amrex. You will need FFTW3 for axionyx to compile. GNUMakefile for example runs are provided for two typical systems, an arm64 Mac and x86 Linux.
